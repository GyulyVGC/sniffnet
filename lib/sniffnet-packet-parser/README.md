# sniffnet-packet-parser

Network packet parser for Sniffnet.

Powered by [`etherparse`](https://github.com/JulianSchmid/etherparse).

## Supported protocols

- `TCP`
- `UDP`
- `ICMPv4`
- `ICMPv6`
- `ARP`

## Supported link types

- `ETHERNET`
- `NULL`
- `LOOP`
- `IPV4`
- `IPV6`
- `RAW`
- `LINUX_SLL`
- `LINUX_SLL2`
